# 🎰 РофлКазино

Демо-казино для игры с другом. Деньги **ненастоящие**: каждому игроку при входе дают 10 000 ₽,
а дальше — занимай у мамы 👩 (с процентами и дедлайнами).

## Игры

| Игра | Режим |
|---|---|
| 📈 **Краш 1×1** | дуэль: кто выведет на большем иксе до краша — забирает банк; режим «🙈 Вслепую» |
| 💣 **Мины** | соло (с множителями) или дуэль: одинаковое поле, кто откроет больше 💎 и вовремя нажмёт «Стоп» |
| 🗼 **Башни** | соло (4 сложности) или дуэль: одинаковая башня, кто выше залез и остановился |
| 🎡 **Рулетка** | общий стол: большие кнопки «Красное / Зеро / Чёрное», под ними ставки игроков; числа и дюжины тоже есть |
| ✈️ **Самолётик** | общий раунд для всех, есть автовывод |
| 📦 **Кейсы** | 13 кейсов от 50 ₽ до 25 000 ₽ (RTP 97%) и кейс-батл (обычный или «🤪 Безумный» — побеждает дешёвый дроп) |
| 🎲 **Кости** | соло «больше/меньше» с выбором шанса и дуэль «🪙 Монетка 1×1» |

## 👩 Мама-банк

* Займы на выбор (5 000 – 75 000 ₽) с процентами и **дедлайном**. Доступные суммы зависят от **доверия мамы**.
* Просрочка: 📞 мама звонит и капает пеня 3%/мин → через 3 мин 😡 забирает половину прибыли с выигрышей →
  через 10 мин 🔒 домашний арест (ставки не больше 1 000 ₽).
* Можно вернуть частично, попросить отсрочку (один раз, +10%) или закрыть долг друга.
* Выбраться из ямы помогут 🧹 подработка и 👵 бабушка (раз в 30 минут даёт денег).
* 👤 Профиль игрока открывается по нажатию на ник: место по капиталу, статистика по играм, история ставок.

## 🏢 Имущество

* Квартиры (от комнаты в общаге до виллы) — сдаёшь жильцам на выбор: ненадёжные платят больше, но могут сбежать с кассой.
* Бизнесы (от шаурмичной до своего казино) — приносят доход сами, бывают налоговые, поломки и ажиотаж.
* Доход копится в кассе даже офлайн (до 60 минут), улучшения, продажа за 70%. Имущество входит в капитал.

Подробное ТЗ обновления — в [docs/UPDATE_v2.md](docs/UPDATE_v2.md).

## Запуск

```bash
npm install
npm start          # http://localhost:3000
```

Порт меняется через `PORT`, файл с балансами — через `DATA_FILE` (по умолчанию `data.json` рядом с server.js).
`DEBT_TIME_SCALE` ускоряет сроки долгов (например, `0.1` — в 10 раз быстрее, для тестов).

## Как играть с другом

Другу нужен доступ к серверу. Варианты:

1. **Бесплатный хостинг (Render.com):** New → Web Service → подключить этот репозиторий,
   *Build Command* = `npm install`, *Start Command* = `npm start`.
   Получите ссылку вида `https://xxx.onrender.com` — кидаете её другу.
   (На бесплатном тарифе сервер засыпает и при перезапуске балансы сбрасываются — для рофла норм.)
2. **С домашнего компьютера:** запустить `npm start`, затем `npx cloudflared tunnel --url http://localhost:3000`
   (или ngrok) — получите публичную ссылку для друга.
3. **В одной Wi-Fi сети:** другу достаточно открыть `http://<ваш-локальный-IP>:3000`.

Вход — по нику; ник привязывается к браузеру, так что занять чужой не получится.
